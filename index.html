Règle : une région de n cases contient les chiffres 1 à n, et deux cases voisines, même en diagonale, ne portent jamais le même chiffre.

resoudre.c
/* Backtracking : essayer, vérifier, revenir en arrière. */
bool resoudre(grille *g, int k) {
    if (k == g->n * g->n) return true;
    int i = k / g->n, j = k % g->n;
    if (g->val[i][j]) return resoudre(g, k + 1);
    for (int v = 1; v <= taille_region(g, i, j); v++) {
        if (!valide(g, i, j, v)) continue;
        g->val[i][j] = v;
        if (resoudre(g, k + 1)) return true;
        g->val[i][j] = 0;  /* retour arrière */
    }
    return false;
}

04Développement durable & engagement

Optimiser, c'est aussi consommer moins.

Mon TIPE m'a appris qu'un gain de rendement est d'abord une économie d'énergie. Dans le numérique, l'enjeu est le même : les centres de calcul consomment énormément d'électricité, et chaque optimisation compte.

Sobriété numérique

Un code efficace, c'est moins de calcul inutile, donc moins d'énergie consommée. C'est l'un des fils conducteurs de mon orientation vers le HPC.

Mesurer pour décider

Temps d'exécution, mémoire, énergie : mesurer d'abord permet de cibler les optimisations qui réduisent vraiment l'empreinte d'un programme.
