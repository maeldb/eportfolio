Solveur de grilles de Suguru en C

Représentation, affichage et vérification de grilles, puis résolution par force brute, algorithme glouton et backtracking : une grille 8×8 résolue en moins d'une seconde.

  • Algorithmique

SituationProjet de programmation en classes préparatoires MP2I.
T
TâcheReprésenter, afficher et vérifier des grilles de Suguru, puis les résoudre automatiquement.

RésultatUne grille 8×8 résolue en moins d'une seconde.

Règle : une région de n cases contient les chiffres 1 à n, et deux cases voisines, même en diagonale, ne portent jamais le même chiffre.

resoudre.c
/* Backtracking : essayer, vérifier, revenir en arrière. */
bool resoudre(grille *g, int k) {
    if (k == g->n * g->n) return true;
    int i = k / g->n, j = k % g->n;
    if (g->val[i][j]) return resoudre(g, k + 1);
    for (int v = 1; v <= taille_region(g, i, j); v++) {
        if (!valide(g, i, j, v)) continue;
        g->val[i][j] = v;
        if (resoudre(g, k + 1)) return true;
        g->val[i][j] = 0;  /* retour arrière */
    }
    return false;
}
